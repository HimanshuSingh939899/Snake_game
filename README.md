# Snake Game

A Snake game I made in Python using the turtle module. This is my first project on GitHub.

## About

You control a snake with the arrow keys and eat food to grow and score points. The game resets if you hit the wall or run into your own body. It also keeps track of your high score while the game is open.

## How to run

You only need Python 3 installed. turtle comes with it, so there is nothing else to install.

```
git clone https://github.com/HimanshuSingh939899/Snake_game.git
cd Snake_game
python snake.py
```

Use the arrow keys to play.
